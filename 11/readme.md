問 最強事後条件を計算するアルゴリズムを考えよ
最弱事後条件を求めた手順を逆にたどれば良いと考えた。授業で示された4つの構文について考える。
まず連結について、{P}S{Q}について、Qが最強事後条件のとき Q = sp(S, P)と書くとする

{P}skip{ }について、wp(skip, Q) = Q より 事後条件は P となる
{P}x := e{ }について、wp(x := e, Q) = [x↦e]Q より  [e↦x]P
{P}S1; S2{ } について、wp(S1;S2, Q) = wp(S1, wp(S2, Q))より sp(S2, sp(S1, P))
{P}if b then S1 else S2{ } について、b ⇒ sp(S1, P) ∧ ¬b ⇒ sp(S2, P)

のようにwpの逆の演算を行っていけば最強事後条件を求めることができると考えた
